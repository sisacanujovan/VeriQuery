
# 🔍 VeriQuery

### Ask. Analyze. Verify.

**VeriQuery** is an Agentic GenAI-powered data analyst that helps users analyze multiple datasets and documents while ensuring that every numerical answer is **verified and reproducible**.

Instead of simply giving an answer, VeriQuery provides the **Answer, Evidence, Code, and Confidence** behind each result.

---

## 🚀 Features

* 📁 Upload multiple files at once
* 📊 Analyze CSV and Excel datasets
* 📄 Process PDF and text-based data
* 🔗 Discover relationships between tables
* 🤖 Ask questions using natural language
* 🧮 Perform data analysis automatically
* ✅ Verify numerical results before answering
* 🔎 Detect duplicates, missing values, conflicting data, and other data-quality issues
* 💻 Provide reproducible analysis code
* ⚠️ Identify ambiguous or unanswerable questions
* 📥 Download analysis results as an Excel report

## 🎯 The Problem

AI can answer questions about data, but **can it prove the answer?**

Real-world data is often messy:

* Missing values
* Duplicate records
* Different units
* Ambiguous dates
* Conflicting tables
* Incomplete information

A system that gives a confident answer without checking these problems can produce unreliable results.

---

## 💡 Our Solution

VeriQuery follows a **"Verify Before You Answer"** approach.

For every result, the system attempts to provide:

### 1. Answer

The calculated result for the user's question.

### 2. Evidence

The files, tables, columns, filters, and assumptions used.

### 3. Code

The analysis logic used to calculate the result.

### 4. Confidence

An indication of whether the result is verified, uncertain, or cannot be reliably determined.

If the data cannot support a reliable answer, VeriQuery can respond:

> **"I can't determine this from the available data."**

## 📥 Excel Report

VeriQuery can generate a downloadable report containing:

* **Answer** — final results
* **Proof** — analysis code and verification
* **Evidence** — source files and columns
* **Data Quality** — detected issues
* **Sources** — data used for each result
* **Refusals** — questions that could not be answered reliably

---

## 🛡️ Trust & Verification

VeriQuery is designed around four principles:

```text
CORRECT
Is the answer mathematically correct?

REPRODUCIBLE
Can the calculation be run again?

ALERT
Were data-quality problems detected?

HONEST
Does the system refuse when the data is insufficient?
```

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/sisacanujovan/VeriQuery.git
cd VeriQuery
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate it

**Windows:**

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run VeriQuery

```bash
streamlit run app.py
```

The application will open in your browser.

## 🔑 Optional AI Configuration

VeriQuery can optionally use Gemini for natural-language query planning.

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-2.5-flash
```

**Never upload your API key to GitHub.**
